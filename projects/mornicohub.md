
# MornicoHub
## Personal Data Management & Automation

### Overview

MornicoHub is a personal software project developed to organize, process and analyze personal work-related and vehicle data.

The application brings together different tools designed to simplify repetitive calculations, compare information and make personal data easier to understand.

---

### Main Modules

#### 1. Working Time & Payslip Analysis

A module focused on processing working time records and estimating payroll information.

**Key features:**
- Automatic acquisition and processing of clock-in records.
- Organization of working time information.
- Calculation of estimated payroll amounts.
- Comparison between personal estimates and declared payslip data.
- Historical data management.

#### 2. Vehicle Consumption Tracking

A separate module designed to monitor personal vehicle consumption.

**Key features:**
- Recording of refuelling information.
- Monitoring of fuel consumption.
- Historical data organization.
- Analysis of vehicle usage trends.

---

### Project Objectives

- Reduce repetitive manual calculations.
- Organize personal information in a structured way.
- Compare data from different sources.
- Make historical information easier to consult.
- Provide useful insights through automated processing.

---

### Technologies & Concepts

- Web application development
- Data processing and analysis
- Calculation logic
- Process automation
- Data organization
- AI-assisted development

---

### Project Approach

MornicoHub was developed to address everyday needs through practical software solutions.

The project combines data collection, automated processing and calculation logic to transform raw information into useful and understandable results.

**MornicoHub demonstrates how software and automation can simplify personal data management and recurring calculations.**
